ArtisanFlow

Style Customization System for Illustration Generation

ArtisanFlow is a practical framework that enables illustrators to integrate their personal artistic styles into AI-assisted generation workflows with only tens of original samples.

Key Highlights

  • 🎨 LoRA-based fine-tuning for high-fidelity style adaptation
  • 🧠 Prompt engineering to enhance consistency across layers and poses
  • 🧩 Compatibility with ControlNet and Layer Diffusion pipelines
  • 🧰 Modular and node-based UI built on ComfyUI
  • 💻 Efficient inference on 24GB consumer-grade GPUs
